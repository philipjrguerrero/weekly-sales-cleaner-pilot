# Weekly Sales Cleaner Pilot

This is a pre-release, documentation-only feedback pilot for a tool that reviews and cleans a specific USD sales-line CSV format. No software is distributed here.

## Invitation

I'm developing a small tool for reviewing and cleaning a specific USD sales-line CSV format. I'm looking for a merchant or bookkeeper who regularly handles sales CSVs to help check whether the workflow is useful. To start, please share only the platform/report name and column headers you're permitted to share. Don't post customer details, financial records, credentials, or actual transaction files. No installation or payment is requested at this stage, and support for native Shopify, Etsy, or other exports is not yet established.
